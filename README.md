# Podnikatelská mapa Lomnice nad Popelkou

Interaktivní mapa ekonomických subjektů v okruhu 5 km od Lomnice nad Popelkou.

## Aktuální stav
- Leaflet mapa s OpenStreetMap podkladem
- okruh 5 km
- vyhledávání subjektu / IČO / adresy
- filtry podle oboru, velikosti, právní formy a vzdálenosti
- detail subjektu po kliknutí
- připravena datová vrstva `data/firms.json`

## Datový plán
Primárním zdrojem bude Registr ekonomických subjektů (RES) Českého statistického úřadu. Kategorie počtu pracovníků z RES budou vedena odděleně od budoucího odhadu počtu pracovních míst fyzicky v Lomnici nad Popelkou.

## Poznámka
Současný soubor `data/firms.json` obsahuje pouze demonstrační záznam. Před veřejným nasazením je nutné nahradit jej skutečnými daty a ověřit geolokaci adres.
